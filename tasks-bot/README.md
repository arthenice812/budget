# 📌 Бот задач в Telegram

Личный планировщик вместо «Избранного», плюс общие проекты с руководителем и коллегами.
Пишешь задачу боту — он запоминает срок, держит актуальный список закреплённым наверху чата,
сам напоминает, а на доске (мини-приложение внутри Telegram) всё видно колонками, как в Асане.

Подробная справка с примерами есть и в самом боте: кнопка **«❓ Помощь»** внизу чата.

---

## Где что находится

### Меню внизу чата (всегда на месте)
```
[📋 Задачи]   [⭐ Главное]  [📅 Встречи]
[📁 Проекты]  [🗂 Доска]    [❓ Помощь]
```
Если меню спряталось — значок с квадратиками рядом с полем ввода или команда `/menu`.
Новый проект — «📁 Проекты» → «➕ Создать проект».

### Закреплённое сообщение наверху чата
«📌 Мои задачи» — всегда актуальный список: ⭐ Главное → 🔴 Просрочено → 📍 Сегодня → 🔜 Завтра →
🗓 Неделя → 📆 Позже → 📥 Без срока → 📤 Поручено другим. Обновляется само. Пропало — `/pin`.

### Кнопки под карточкой задачи
```
[✅ Готово] [📅 Срок] [☑ 0/2] [☰ Ещё]
```
| Кнопка | Что внутри |
|---|---|
| **✅ Готово** | отметить выполненной (регулярная — перенесётся на следующий раз) |
| **📅 Срок** | Сегодня · Завтра · +неделя · ✏️ Своя дата · Без срока · **▶️ Начать…** · **🔁 Повтор** (у регулярной — «⏭ Пропустить раз»). После нажатия можно просто написать дату сообщением: `7 октября 15:00` |
| **☑ 0/2** | чек-лист — только если в задаче есть пункты; нажимаешь на пункт — он отмечается |
| **☰ Ещё** | 🔁 Повтор · 📁 Проект · 👤 Кому · 🔥 Важно · 🔔 Не отстану · ⏳ Жду ответа · 🏷 Статус (в проектах) · 📎 Файлы · 🗑 Удалить |

В каждом меню есть «← Назад». На напоминании вместо «Срок»: **🔔 +1 час** и **🔔 Завтра** — отложить.

## Что умеет

### 📝 Задачи
| Ты пишешь | Бот делает |
|---|---|
| `Отчёт для Маши до пятницы` | задача со сроком, карточка с кнопками |
| `Позвонить врачу завтра в 10 утра` · `… 10:00` · `… 10.00` | срок со временем: напомнит за час и в срок |
| `Сдать отчёт 25.10 !!` или `Срочно ответить Олегу` | важная 🔥 — всегда выше остальных |
| Несколько строк | первая — задача, остальные — подробности, строки с «-» — чек-лист |
| 🎙 Голосовое | расшифрует и создаст задачу |
| Пересылаешь сообщение из «Избранного» или чата | сделает из него задачу |
| 📎 Фото, скриншот, документ (с подписью или без) | задача с вложением; альбом — одна задача; файл в ответ на карточку — прикрепится |
| `Отчёт начать в среду, сдать в пятницу` | дата начала + дедлайн: в «Сегодня» появится в среду |

### 🗒 После собрания
**Ответь (reply) на карточку задачи** — текст допишется в подробности, строки с «-» — в чек-лист.
Ответ датой (`в понедельник`, `12.10 15:00`) — переносит срок. Карточку можно найти через «📋 Задачи» → номер `/t12`.

### ✏️ Словами, без кнопок
| Пишешь | Что будет |
|---|---|
| `удали задачу позвонить маме` · `отмени созвон` | удалит (с кнопкой «↩️ Восстановить»); похожих несколько — даст выбрать |
| `готово отчёт` · `сделала звонок врачу` | отметит выполненной |
| `перенеси отчёт на пятницу 15:00` | перенесёт срок |
| `удали` / `готово` без названия | покажет список задач кнопками |
| ответ на карточку одним словом: `готово`, `удали` | сделает это с этой задачей |

### 📅 Сроки, которые бот понимает
- **день:** сегодня, завтра, послезавтра, в пятницу, до пт, в следующую среду
- **дата:** 25.10, 25.10.2027, 12 октября, 10 числа
- **через:** через 3 дня / 2 недели / месяц, через 30 минут, через 2 часа
- **неделя и месяц:** на следующей неделе (понедельник), в конце недели (пятница), в конце месяца, в следующем месяце (1-е)
- **время:** 15:00, 15.30, в 9.45, в 18, в 10 часов 30 минут, в 10 утра, в 7 вечера, утром (9:00), к обеду (13:00), вечером (19:00)
- **час без «утра/вечера»:** «в 2»…«в 6» — это день (в 3 = 15:00); «сегодня в 9», сказанное днём, — 21:00
- **«начать … сдать …»:** `начать отчёт в понедельник, сдать в пятницу` — пятница после начала
- **опечатки:** «31 сентября», «25:00» — бот скажет, что такой даты нет, и не создаст из этого задачу

Если неясно, дата это или время (`10.11`), — бот спросит кнопками «📅 Дата / 🕐 Время».

**Поменять срок:** «📅 Срок» на карточке → кнопка или просто напиши дату сообщением · «✏️ Своя дата» ·
ответ (reply) датой на карточку · `перенеси отчёт на пятницу`. Если написать только дату, бот спросит, к какой задаче её применить.

### 🔁 Регулярные задачи
**Кнопкой:** 📅 Срок (или ☰ Ещё) → **🔁 Повтор** → готовые варианты от даты задачи:
каждый день · по будням · каждую неделю · раз в 2 недели · каждый месяц · каждый год ·
1-й рабочий день месяца · последний рабочий день.

**«⚙️ Настроить подробно»** — форма как в календаре: по дням / неделям (несколько дней, раз в N недель) /
месяцам (число, n-й или последний день недели, последний день, первый/последний рабочий день) / годам,
и «сколько повторять» — всегда или до даты.

**Или текстом:**
| Пишешь | Как повторяется |
|---|---|
| `Витамины каждый день в 9:00` | ежедневно в 9:00 |
| `Отчёт каждый понедельник` · `Планёрка по вторникам и четвергам` | по дням недели |
| `Зарядка по будням` · `Уборка по выходным` | пн–пт / сб–вс |
| `Созвон каждые 2 недели по четвергам` | раз в 2 недели |
| `Интернет каждое 10 число` · `Аренда каждое первое число` | число месяца |
| `Табель в последний день месяца` | последний день месяца |
| `Отчёт в первый рабочий день месяца` | первый рабочий день — с учётом праздников и переносов (производственный календарь [isdayoff.ru](https://isdayoff.ru)) |
| `Планёрка каждый первый понедельник месяца` | n-й день недели |
| `Ежемесячная задача …`, `Ежедневная планёрка …` | тоже повтор |

✅ — задача переносится на следующий раз, пропущенные разы не копятся.
**Случайно нажато «Готово»?** Сразу на карточке — «↩️ Отменить «Готово»», позже — в ☰ Ещё.
Если бот видит слова про повтор, но не понял их, — он об этом скажет. Все регулярные: `/repeat`.

### 📁 Проекты и руководитель
1. **Создать:** **«📁 Проекты»** внизу → **«➕ Создать проект»** → название (или напиши `создай проект Работа`).
2. **Позвать:** сразу будет кнопка **«👥 Позвать людей»** — выбираешь руководителя в Telegram, он открывает ссылку и жмёт «Старт».
   Позже: «📁 Проекты» → «👥 Позвать».
3. **Задача в проект:** под новой задачей кнопка «📁 Работа», или текстом `Работа: отчёт до пятницы`.
   Переложить потом: ☰ Ещё → 📁 Проект.
4. **Поручить:** под задачей в общем проекте — кнопки с именами («👤 Анна»), или ☰ Ещё → 👤 Кому.
5. **Статусы:** «☰ Ещё» → «🏷 Статус» → К выполнению / В работе / На проверке / Готово — автору приходит уведомление, проект в «📁 Проекты» разложен по статусам.
6. Исполнитель отмечает ✅ или дописывает подробности — автору приходит уведомление. Свои поручения — в «📤 Поручено другим».

Личные задачи никто не видит. Удалить задачу может только автор. Весь проект по людям: «📁 Проекты» → нажать на проект.

**Удалить проект:** «📁 Проекты» → нажать на проект → «🗑 Удалить проект» (или `удали проект Тест`).
Можно оставить задачи — они станут личными, или удалить вместе с ними. Удаляет только создатель, остальные могут «🚪 Выйти».

### 📅 Встречи из Яндекс Календаря
**Подключить** ([справка Яндекса](https://yandex.ru/support/yandex-360/customers/calendar/web/ru/sync/export)):
1. calendar.yandex.ru в браузере → в списке календарей слева навести курсор на свой календарь → ⚙️.
2. Вкладка «Экспорт» → формат iCal → «Скопировать».
3. Прислать ссылку боту обычным сообщением — бот проверит, что календарь читается, покажет встречи на неделю и удалит сообщение со ссылкой.

Ссылка iCal есть только у владельца календаря. Бот перечитывает календарь раз в 15 минут.
- утром — «Встречи сегодня» в плане дня; кнопка «📅 Встречи» — на 7 дней;
- **по понедельникам** — встречи недели с кнопками «📝»: выбираешь встречу, пишешь, что подготовить → задача с чек-листом и сроком до начала встречи;
- **уже записанную задачу — к встрече:** на карточке «☰ Ещё» → «🗓 К встрече» → выбери встречу (ближайшие 2 недели).
  Или со встречи: «📅 Встречи» → нажми встречу → «📎 Добавить уже записанную задачу». Если срок задачи был позже
  встречи (или его не было), он станет «до начала встречи». Регулярная задача к регулярной встрече после «Готово»
  сама переезжает к следующей встрече серии. Отвязать — там же, «✖ Не привязывать к встрече»;
- **за час, за 15 минут и в момент начала** — напоминание со ссылкой на звонок, списком подготовки и задачами к встрече;
  после встречи бот напомнит отметить то, что к ней было не сделано;
- **после регулярной встречи** — «🗒 Записать задачи по итогам» (каждая строка — задача) и «➡️ Подготовить к следующей».

Бот только читает календарь (повторяющиеся, перенесённые и отменённые встречи учитываются).

### 🗂 Доска
**Доска в чате** («🗂 Доска» внизу) работает без VPN: вкладки Сегодня · Неделя · Позже · Без срока · Поручено · Проекты (по статусам), задачи — кнопками, листание ◀ ▶.

**Большая доска** (мини-приложение) — нужен VPN: встроенный прокси Telegram её не пропускает.
Открыть: «🌐 Большая доска» под доской в чате или «Доска» слева от поля ввода. Колонки: Просрочено → Сегодня → Завтра → Неделя → Позже → Без срока → Готово.
- Перетащи карточку (долгое нажатие) в другую колонку — срок поменяется; в «Готово» — закрыта.
- Фильтры: Мои / Все / Поручено / по проектам; «＋ Проект» — создать проект.
- Нажми на карточку: название, срок, 🔥, ⭐ главное, повтор (форма), проект, исполнитель, чек-лист, подробности.
- «+» — новая задача тем же языком, что в чате.

### 🧠 Напоминания и сводки
- ☀️ **9:00** — план на день и кнопки «выбери до 3 главных задач» — одним сообщением.
- 🧹 **Утром** — одна задача, которая лежит без срока больше 2 недель: «ещё актуально?»
- 📍 **12:00 и 17:00** — задачи на сегодня без времени.
- ⏰ **За час и в срок** — задачи со временем (с кнопками «отложить»).
- 🔔 **«Не отстану»** — важные 🔥 задачи (или любые по кнопке): каждые полчаса с 9 до 21, пока не отмечены. Старое напоминание удаляется.
- 📅 **Встречи** — за час, за 15 минут и в момент начала.
- 🌙 **20:00** — вечерняя сверка по главным задачам и кнопка «⏩ Всё несделанное — на завтра» (с «↩️ Вернуть»). Словами: `перенеси всё на понедельник`.
- ⏳ **«Жду ответа»** — задачи, где ждёшь другого человека («☰ Ещё» → «⏳ Жду ответа», или задача начинается со слова «Жду»): лежат отдельно, не «горят»; в назначенный день утром бот спрашивает «пришёл ли ответ?» и даёт готовый текст напоминания.
- 📊 **Воскресенье 19:00** — итоги недели.

**Не приходят напоминания?** Напиши боту `/status` — он покажет, работает ли расписание и какое у него время.

**Команды:** `/meetings` · `/calendar` · `/list` · `/today` · `/focus` · `/projects` · `/invite` · `/repeat` · `/done` · `/week` · `/t12` · `/pin` · `/status` · `/board` · `/help`

## Установка (≈20 минут, бесплатно, без программирования)

Бот работает на Cloudflare Workers — это бесплатно, свой сервер не нужен.

### 1. Создать бота в Telegram
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username (должен заканчиваться на `bot`).
2. Скопируй **токен** (вида `123456:ABC-...`).

### 2. Создать Worker
1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com).
2. **Workers & Pages → Create → Start with Hello World!** → назови `tasks-bot` → **Deploy**.
3. Открой файл [`worker.js`](worker.js) на GitHub → кнопка **Raw** → выдели всё → скопируй.
4. В Cloudflare: **Edit code** → удали всё → вставь → **Deploy**.

### 3. Создать базу данных
1. **Storage & Databases → D1 SQL Database → Create** → имя `tasks`.
2. Вернись в Worker → **Settings → Bindings → Add binding → D1 database**: Variable name `DB`, база `tasks`.

### 4. Голосовые (по желанию)
Worker → **Settings → Bindings → Add binding → Workers AI** → Variable name `AI`.

### 5. Переменные
Worker → **Settings → Variables and Secrets → Add**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от BotFather |
| `WEBHOOK_SECRET` | Secret | придуманный пароль **только из латинских букв и цифр**, например `Rina2026tasksXk9` |
| `TIMEZONE` | Text | `Europe/Moscow` (или свой: `Asia/Yekaterinburg`, `Europe/Samara`…) |
| `MORNING_AT` / `EVENING_AT` / `WEEKLY_AT` | Text | необязательно: `09:00` / `20:00` / `19:00`, `off` — выключить |
| `DAY_REMIND_AT` | Text | необязательно: напоминания о задачах «на сегодня», по умолчанию `12:00,17:00` |
| `NAG_EVERY` / `NAG_FROM` / `NAG_TO` | Text | необязательно: «не отстану» — раз в сколько минут (`30`, `0` — выключить) и с какого по какое время (`09:00`–`21:00`) |
| `MEET_REMIND` | Text | необязательно: за сколько минут напоминать о встрече, через запятую (по умолчанию `60,15,0` — за час, за 15 минут и в начале) |

### 6. Включить напоминания
Worker → **Settings → Trigger Events → Add → Cron Triggers** → `*/5 * * * *` (каждые 5 минут).
Время «Next» там показано по UTC (на 3 часа меньше московского) — это нормально.

### 7. Подключить бота к Telegram
Открой в браузере (подставь свой адрес воркера и пароль):
```
https://tasks-bot.<твой-поддомен>.workers.dev/setup?secret=<WEBHOOK_SECRET>
```
Должно показать `"ok": true` в разделах webhook, commands и menu.

### 8. Готово
1. Напиши боту `/start` — придут справка и меню внизу.
2. Напиши `/status` — проверь, что напоминания «✅ работают» и время совпадает с твоим.
3. Добавь переменную `ALLOWED_USERS` = свой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)) —
   бот будет отвечать только тебе и тем, кого ты пригласишь в проект.

Перенос старых задач: «Избранное» → выдели сообщения → Переслать → в бота.

### Обновление
1. Открой [`worker.js`](worker.js) → **Raw** → скопируй всё.
2. Cloudflare → `tasks-bot` → **Edit code** → вставь вместо старого → **Deploy**.
3. Если в описании изменений сказано, что поменялись команды, — ещё раз открой ссылку `/setup?secret=…`.

Задачи и настройки при обновлении сохраняются.

## Последние изменения
- **Править название задачи:** на карточке «☰ Ещё» → «✏️ Название» и прислать новое; или ответом на карточку
  `название: …` / `переименуй в …`; на доске — прямо в поле названия. Второй стороне приходит «✏️ переименовал(а) задачу».
  Название общей задачи меняет автор — оно обновится у всех копий.
- **Приветствие при входе по ссылке-приглашению:** новичок, пришедший по ссылке проекта, теперь получает то же
  приветствие, что и по /start, и вопрос о рабочем графике.
- **Одна задача нескольким людям:** `Отдел: @Анна @Петя сверить акты`, `Отдел: всем сдать отчёт` или на карточке
  «👥 Нескольким…» и галочки. У автора — одна общая задача с прогрессом «👥 1/3», у каждого исполнителя — своя копия.
  Автору приходит «✅ Анна сделал(а) (1/3)» и «🎉 Все сделали». Название, срок, важность, новые подробности и пункты чек-листа, изменённые у автора,
  обновляются у всех; ☰ Ещё → «👥 Кому» — снять или добавить человека; закрыть/удалить у автора — закрывается/удаляется у всех.
  Повторяющаяся общая переходит на следующий раз, когда сделали все. В другой проект общую задачу не перенести.
- **Переименовать проект:** «📁 Проекты» → проект → «✏️ Переименовать», словами `переименуй проект Тест в Отдел`
  или на большой доске (выбери проект в фильтре → «✏️ Переименовать»). Может создатель проекта; участникам придёт сообщение.
- **Выполненное везде с датой завершения:** `/done` — по дням; на доске в чате вкладка «✅ Готово»; на большой доске
  колонка «Готово» за месяц с датой на каждой карточке; в закреплённом списке — «✅ Сделано сегодня: N».
- **Очистить выполненное:** «🧹» в `/done`, на обеих досках. Свои выполненные удаляются насовсем, поставленные
  другими — пропадают только из твоего списка (у автора остаются). Одну задачу — 🗑 на её карточке.
- **Напоминание о сроке — «⏰ До срока 1 час»** вместо «Через час срок» (читалось как «через час сорок»).
- **Встречи из календаря — три напоминания:** за час, за 15 минут и в момент начала; если проверка опоздала,
  приходит только ближайшее.
- **Одна ссылка на весь отдел:** ссылку-приглашение из `/invite` можно кинуть в общий чат — по ней заходят все;
  о каждом новичке сообщение получает только создатель проекта, остальных не засыпает.
- **«Жду ответа» — свой день:** «⏳ Жду ответа» → «✏️ Свой день» (в четверг, 12.10, через 2 недели); словами — `спросить в четверг`
  ответом на карточку или сразу после «Жду ответа»; в утреннем «Пришёл ли ответ?» — «✏️ Другой день».
- **Свой рабочий график у каждого:** при первом запуске бот спрашивает начало и конец рабочего дня и выходные
  (поменять — `/schedule` или `график 10-19`). От графика считаются план дня, напоминания «на сегодня», сверка,
  «не отстану» и итоги недели; в выходные и праздники (по производственному календарю) бот не беспокоит.
- **Напоминание «за час» пишет правду:** если срок перенесли на «через 40 минут», «Через час срок» больше не приходит
  (придёт «Время пришло!» в срок); если проверка задержалась — пишет, сколько осталось на самом деле.
- **Меню внизу компактнее:** две строки по три кнопки; «➕ Новый проект» убран из меню — он есть в «📁 Проекты».
- В `/status` видна **версия бота** — по ней понятно, какой код сейчас работает в Cloudflare.
- **Изменить подробности:** «☰ Ещё» → «✏️ Подробности» — бот присылает текст, его копируешь, правишь и присылаешь
  целиком; есть «↩️ Вернуть как было». Быстро ответом на карточку: `убери детали`, `удали чек-лист`, `убери <слова>`.
- **Доска:** подробности — одно поле, которое можно править; пункты чек-листа правятся и удаляются (✕);
  название и подробности сохраняются и при закрытии карточки.
- Пропало нижнее меню — команда `/menu`; после обновления бот сам пришлёт меню заново.
- **Надёжность:** если база Cloudflare не примет какой-то индекс, бот всё равно работает (раньше мог замолчать целиком).
- **Бот стал в десятки раз экономнее к лимитам Cloudflare:** календарь записывается в базу, только когда в нём что-то
  поменялось (раньше — каждые 15 минут), а проверка по расписанию читает только открытые задачи, а не всю историю.
  Было: хватало на ~4 человек с календарём. Стало: см. «Сколько людей потянет бесплатный Cloudflare».
- **Задачи к встречам:** уже записанную задачу можно добавить к встрече — с карточки («☰ Ещё» → «🗓 К встрече»)
  или со встречи («📎 Добавить уже записанную задачу»). Она появится в напоминании о встрече.
- Исправлено: если у двоих одна и та же встреча в календаре, подготовка одного больше не попадает в напоминание другому.

  «на следующей неделе», «в конце недели/месяца», «напомни …», «важно: …», «начать … сдать …».
- **Опечатки в датах** («31 сентября», «25:00») — бот говорит, что такой даты нет, а не создаёт задачу молча.
- Если задачу у тебя забрали, бот об этом пишет, а старые кнопки объясняют, что задача больше не у тебя.
- **Новые проверки:** неделя жизни бота по расписанию с нажатием каждой кнопки и доска в настоящем браузере.
- **Исправлено:** кнопки встреч в сообщении «Календарь подключён» отвечали «Не нашёл эту встречу».
- **Закрытие дня одной кнопкой** и **«Жду ответа»**; подробная инструкция подключения календаря.
- **Встречи из Яндекс Календаря:** напоминания, подготовка к встречам задачами, итоги после встречи, встречи недели по понедельникам.
- **«Не отстану»:** напоминание каждые полчаса, пока задача не сделана.
- **Дата начала и дедлайн.** **Файлы и фото в задачах.** **Статусы в проектах.** **Доска в чате** без VPN.
- Исправлено: «Задача 1 сегодня» больше не превращается в «1».
- **Проверка надёжности.** Бот и расписание больше не затирают изменения друг друга (раньше «Готово» или выбор главного, нажатые в момент рассылки, могли пропасть). ## Ограничения бесплатного Cloudflare
За один запуск — до 50 обращений к базе и 50 запросов наружу, ~10 мс процессора. Бот считает свои запросы и, если в 9:00
сводки нужно разослать многим, отправляет их за несколько проверок по 5 минут.

## Рабочий график
У каждого свой: при первом запуске бот спрашивает кнопками, во сколько начинается и заканчивается рабочий день
и есть ли выходные. Поменять — `/schedule` или словами: `график 10-19`, `график 9:30-18:30 без выходных`.

| Что | Когда (пример для графика 10:00–19:00) |
|---|---|
| ☀️ План дня | в начале дня — 10:00 |
| 📍 «Задачи на сегодня» без времени | через 3 часа после начала и за час до конца — 13:00 и 18:00 |
| 🔔 «Не отстану» | только в рабочие часы — 10:00–19:00 |
| 🌙 Вечерняя сверка | за 30 минут до конца — 18:30 |
| 📊 Итоги недели | в последний рабочий день недели, во время сверки |
| 🏖 Выходные и праздники | тишина (праздники — по производственному календарю) |

Задачи с точным временем и встречи напоминаются всегда. Кто график не настроил — работает по общему
расписанию из настроек Cloudflare (MORNING_AT и т. д., по умолчанию 9:00 / 12:00, 17:00 / 20:00 / вс 19:00).

## Если пришло сообщение «в старом виде»
Много кнопок под напоминанием (+1 час / Вечером / Завтра утром / Сегодня / Завтра…) и подпись
«Ответь на это сообщение — допишу подробности…» — так выглядели самые первые версии. Значит, в Cloudflare
работает **ещё одна, старая копия бота** со своим расписанием (Cron) и шлёт напоминания параллельно.
1. Cloudflare → **Workers & Pages** — посмотри, сколько там Workers.
2. В каждом: **Edit code** → поиск (Ctrl+F) `Ответь на это сообщение`. Нашлось — это старая копия.
3. У старой: **Settings → Delete** (удалить Worker). База D1 при этом не удаляется.
4. Проверь новую: напиши боту `/status` — версия должна совпадать с той, что в `worker.js` на GitHub (строка `const BUILD`).

## Сколько людей потянет бесплатный Cloudflare
Замерено в тестах: сутки работы с годом истории задач, календарём и проектами.

| Лимит бесплатного тарифа | Сколько тратит один человек в сутки | Хватит примерно на |
|---|---|---|
| D1: 5 млн прочитанных строк в сутки | ~14 тыс. | ~350 человек |
| D1: 100 тыс. записанных строк в сутки | ~800 | ~120 человек |
| Workers: 100 тыс. запросов в сутки | 288 проверок по расписанию на всех + каждое сообщение и кнопка | ~1000 человек |
| Workers: 10 мс процессора на запуск | проверка каждые 5 минут обходит всех | **15–20 человек** — это первый предел |

Итого: для себя, руководителя и команды до ~15 человек бесплатного тарифа хватает с запасом.
Если людей станет больше, в пиковые минуты (утренняя и вечерняя сводка) проверка может не уложиться в 10 мс;
тогда — тариф Workers Paid за $5 в месяц (30 секунд процессора, лимиты базы в тысячи раз больше).

**Где смотреть расход:** в панели Cloudflare
- **Workers & Pages → бот → Metrics** — запросы, ошибки, время процессора (смотри «CPU time», особенно максимум);
- **Storage & Databases → D1 → база → Metrics** — прочитанные и записанные строки за сутки, размер базы.

**Где хранятся данные.** Не в Telegram: в Telegram только переписка каждого человека с ботом.
Задачи, проекты, ссылки на календари и встречи лежат в базе D1 **в аккаунте Cloudflare владельца бота**.
Через бота каждый видит только свои задачи и задачи общих проектов. Но владелец аккаунта технически может
открыть базу (D1 → Console) и увидеть всё — если ботом пользуются другие люди, им стоит об этом знать.

## Для разработки
```
src/bot.js      — логика бота
src/app.html    — доска (Telegram Mini App)
npm run build   — собрать worker.js (его вставляют в Cloudflare)
npm test        — сборка + тесты (Node 22+, база эмулируется через node:sqlite).
                  Тесты строгие: проверяют разметку и длину каждого сообщения по правилам Telegram,
                  падают на «undefined»/«NaN» в тексте и кнопках и на любой ошибке в логе.
                  Неделя жизни по расписанию: каждые 5 минут, и каждую пришедшую кнопку нажимают —
                  она не должна отвечать «не нашёл / устарело».
                  Доска проверяется в настоящем браузере (если установлен Playwright с Chromium):
                  фильтры, карточки, сроки, повтор во всех вариантах, перетаскивание, удаление.
npx wrangler deploy — деплой из командной строки, см. wrangler.toml
```
