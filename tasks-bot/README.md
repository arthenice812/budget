# 📌 Бот задач в Telegram

Личный планировщик вместо «Избранного»: пишешь задачу боту, он запоминает срок,
держит актуальный список закреплённым наверху чата и сам напоминает.

## Что умеет

| Ты делаешь | Бот делает |
|---|---|
| Пишешь «Отчёт для Маши до пятницы» | Сохраняет задачу со сроком «пт, 2 окт» и присылает карточку с кнопками |
| Пишешь «Позвонить врачу завтра 10:00» | Срок со временем: напомнит за час и ровно в 10:00 |
| Добавляешь `!!` или «срочно» | Помечает задачу важной 🔥, она всегда выше остальных |
| Пишешь несколько строк | Первая строка — задача, остальное — подробности |
| **Отвечаешь (reply) на карточку задачи** после собрания | Дописывает текст в подробности задачи |
| Отвечаешь на карточку датой: «в понедельник», «12.10 15:00» | Переносит срок |
| Пересылаешь сообщение из любого чата или из «Избранного» | Превращает его в задачу, указывает, от кого переслано |
| Нажимаешь кнопки на карточке | Сегодня / Завтра / +неделя / Без срока / 🔥 Важно / ✅ Готово / 🗑 |

### 🔁 Регулярные задачи

| Пишешь | Как повторяется |
|---|---|
| Выпить витамины каждый день в 9:00 | ежедневно, напоминание в 9:00 |
| Отчёт по продажам каждый понедельник | каждый пн |
| Планёрка по вторникам и четвергам 11:00 | вт и чт |
| Зарядка по будням / Уборка по выходным | пн–пт / сб–вс |
| Оплатить интернет каждое 10 число | каждый месяц 10-го (в коротких месяцах — последний день) |
| Полить цветы каждые 3 дня | раз в 3 дня |
| … каждую неделю / каждые 2 недели / ежемесячно / каждый год | соответственно |

Нажимаешь ✅ — задача не исчезает, а переносится на следующий раз (пропущенные разы не копятся).
На карточке есть «⏭ Пропустить раз» и «🔁✖» — перестать повторять.
Ответь на любую задачу «каждую пятницу» — она станет регулярной; «не повторять» — снова разовой.
Все регулярные задачи: `/repeat`.

**Закреплённое сообщение** наверху чата всегда показывает актуальный список,
разбитый по группам: 🔴 Просрочено → 📍 Сегодня → 🔜 Завтра → 🗓 Неделя → 📆 Позже → 📥 Без срока.
Листать ничего не нужно: важное всегда сверху.

**Напоминания:**
- ☀️ 09:00 — план на день: просроченное, сегодняшнее, важное без срока;
- 🌙 20:00 — вечерняя сверка: что не закрыто и что на завтра (если нечего — молчит);
- ⏰ за час до срока и в срок, если у задачи указано время.

**Команды:** `/list` — все задачи, `/today` — просрочено/сегодня/завтра, `/done` — выполненные, `/repeat` — регулярные,
`/t12` — открыть задачу №12, `/pin` — заново закрепить список.

**Как бот понимает сроки:** сегодня, завтра, послезавтра, в пятницу / до пт / в следующую среду,
через 3 дня / через 2 недели / через месяц, 25.10 / 25.10.2027, 12 октября, 15:00 / в 9:30.

## Установка (≈15 минут, бесплатно, без программирования)

Бот работает на Cloudflare Workers: это бесплатно, сервер держать не нужно.

### 1. Создать бота в Telegram
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username.
2. Скопируй **токен** (вида `123456:ABC-...`).

### 2. Создать Worker
1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com).
2. **Workers & Pages → Create → Create Worker** → назови `tasks-bot` → **Deploy**.
3. **Edit code** → удали всё → вставь содержимое файла [`worker.js`](worker.js) → **Deploy**.

### 3. Создать базу данных
1. **Storage & Databases → D1 SQL Database → Create** → имя `tasks`.
2. Вернись в Worker → **Settings → Bindings → Add → D1 database**:
   Variable name: `DB`, база: `tasks`.

### 4. Переменные
Worker → **Settings → Variables and Secrets → Add**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от BotFather |
| `WEBHOOK_SECRET` | Secret | любая длинная случайная строка латиницей, например `k7Qp2xVn9sLw4` |
| `TIMEZONE` | Text | `Europe/Moscow` (или свой часовой пояс) |
| `MORNING_AT` | Text | `09:00` — необязательно, `off` чтобы выключить |
| `EVENING_AT` | Text | `20:00` — необязательно, `off` чтобы выключить |

### 5. Включить напоминания
Worker → **Settings → Triggers → Cron Triggers → Add** → `*/5 * * * *` (каждые 5 минут).

### 6. Подключить бота к Telegram
Открой в браузере (подставь свой адрес воркера и секрет):
```
https://tasks-bot.<твой-поддомен>.workers.dev/setup?secret=<WEBHOOK_SECRET>
```
Должно показать `"ok": true`.

### 7. Готово
Напиши боту `/start`. Он покажет твой Telegram ID — добавь переменную
`ALLOWED_USERS` = этот ID, чтобы бот отвечал только тебе.

Перенос старых задач: открой «Избранное», выдели нужные сообщения → Переслать → в бота.
