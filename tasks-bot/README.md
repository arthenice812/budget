# 📌 Бот задач в Telegram

Личный планировщик вместо «Избранного», плюс общие проекты с руководителем и коллегами.
Пишешь задачу боту — он запоминает срок, держит актуальный список закреплённым наверху чата,
сам напоминает, а на доске (мини-приложение внутри Telegram) всё видно колонками, как в Асане.

## Что умеет

### Задачи
| Ты делаешь | Бот делает |
|---|---|
| Пишешь «Отчёт для Маши до пятницы» | Сохраняет задачу со сроком и присылает карточку с кнопками |
| «Позвонить врачу завтра в 10 утра» / «… 10:00» | Срок со временем: напомнит за час и в срок |
| Добавляешь `!!` или «срочно» | Важная 🔥 — всегда выше остальных |
| Пишешь несколько строк | Первая строка — задача, остальное — подробности, строки с «-» — чек-лист |
| 🎙 Отправляешь голосовое | Расшифровывает и создаёт задачу («Напомни позвонить маме завтра в 10 утра») |
| **Отвечаешь (reply) на карточку** после собрания | Дописывает подробности / пункты чек-листа |
| Отвечаешь на карточку датой: «в понедельник», «12.10 15:00» | Переносит срок |
| Пересылаешь сообщение из «Избранного» или любого чата | Делает из него задачу |

Кнопки на карточке: Сегодня / Завтра / +неделя / Без срока / 🔥 / ✅ Готово / 👤 Кому / 🗑,
а у чек-листа — ☐1 ☐2 … чтобы отмечать пункты.

**Сроки, которые бот понимает:** сегодня, завтра, послезавтра, в пятницу / до пт / в следующую среду,
через 3 дня / через 2 недели / через месяц, 25.10 / 25.10.2027, 12 октября, 10 числа, 15:00 / в 9:30 / в 10 утра / в 7 вечера.

### 🔁 Регулярные задачи
| Пишешь | Как повторяется |
|---|---|
| Выпить витамины каждый день в 9:00 | ежедневно, напоминание в 9:00 |
| Отчёт по продажам каждый понедельник | каждый пн |
| Планёрка по вторникам и четвергам 11:00 | вт и чт |
| Зарядка по будням / Уборка по выходным | пн–пт / сб–вс |
| Оплатить интернет каждое 10 число | каждый месяц 10-го (в коротких месяцах — последний день) |
| Полить цветы каждые 3 дня · каждые 2 недели · ежемесячно · каждый год | соответственно |

✅ — задача переносится на следующий раз (пропущенные разы не копятся). «⏭ Пропустить раз» и «🔁✖» — на карточке.
Ответь на задачу «каждую пятницу» — станет регулярной, «не повторять» — снова разовой. Все регулярные: `/repeat`.

### 📁 Проекты и совместная работа
- **Проект = хэштег.** «#ремонт Выбрать плитку до субботы» — проект «ремонт» создаётся сам. Или `/newproject Маркетинг`.
- **Позвать руководителя / коллегу:** `/invite` → бот пришлёт ссылку. Человек открывает её, жмёт «Старт» — и он в проекте.
- **Поставить задачу человеку:** «#маркетинг @Рина Отчёт до пятницы» (по @username или по имени).
  Исполнителю сразу приходит карточка «📨 Новая задача от Анна», и задача появляется в его общем списке
  рядом с личными — с пометкой «(от Анна)».
- **Уведомления второй стороне:** когда исполнитель отмечает ✅, дописывает подробности или срок меняется —
  автору приходит сообщение. И наоборот.
- У автора такие задачи видны в блоке «📤 Поручено другим».
- Личные задачи никто, кроме тебя, не видит. Удалить задачу может только её автор.
- `/projects` — все проекты, `/p12` — проект целиком (по людям), `/list маркетинг` — то же по названию, `/leave_12` — выйти.

### 📋 Доска (мини-приложение)
Кнопка «Доска» слева от поля ввода (или `/board`). Колонки: Просрочено → Сегодня → Завтра → Неделя → Позже → Без срока → Готово.
- Перетащи карточку (долгое нажатие) в другую колонку — срок поменяется; в «Готово» — задача закрыта.
- Фильтры: Мои / Все / Поручено / по каждому проекту.
- Нажми на карточку: название, дата и время, 🔥, ⭐ главное, проект, исполнитель, чек-лист, подробности.
- «+» — новая задача тем же языком, что и в чате.

### 🧠 Чтобы ничего не забыть
- 📌 **Закреплённое сообщение** — всегда актуальный список: ⭐ Главное → 🔴 Просрочено → 📍 Сегодня → … → 📤 Поручено другим.
- ☀️ **Утро (9:00):** план на день + «выбери до 3 главных задач» (кнопками). Главные — наверху списка.
- 🧹 **Залежавшиеся задачи:** если задача без срока лежит больше 2 недель — утром бот спросит «ещё актуально?»
  (📅 на этой неделе / 👍 актуально / ✅ уже сделано / 🗑).
- 🌙 **Вечер (20:00):** сверка по главным задачам — ✅ или ⏩ на завтра одной кнопкой, плюс что не закрыто и что завтра.
- 📊 **Воскресенье (19:00):** итоги недели — что сделано, хвосты, что на следующей неделе. Вручную: `/week`.
- ⏰ **Напоминания** за час и в срок, а на них — 🔔 «+1 час / вечером / завтра утром», чтобы отложить, а не смахнуть.

**Команды:** `/list` · `/today` · `/focus` · `/board` · `/projects` · `/invite` · `/repeat` · `/done` · `/week` · `/t12` · `/pin` · `/help`

## Установка (≈20 минут, бесплатно, без программирования)

Бот работает на Cloudflare Workers — это бесплатно, свой сервер не нужен.

### 1. Создать бота в Telegram
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username.
2. Скопируй **токен** (вида `123456:ABC-...`).

### 2. Создать Worker
1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com).
2. **Workers & Pages → Create → Create Worker** → назови `tasks-bot` → **Deploy**.
3. **Edit code** → удали всё → вставь содержимое файла [`worker.js`](worker.js) → **Deploy**.

### 3. Создать базу данных
1. **Storage & Databases → D1 SQL Database → Create** → имя `tasks`.
2. Вернись в Worker → **Settings → Bindings → Add → D1 database**: Variable name `DB`, база `tasks`.

### 4. Голосовые (по желанию)
Worker → **Settings → Bindings → Add → Workers AI** → Variable name `AI`.
Бесплатного лимита Cloudflare хватает на сотни голосовых в день.

### 5. Переменные
Worker → **Settings → Variables and Secrets → Add**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от BotFather |
| `WEBHOOK_SECRET` | Secret | любая длинная случайная строка латиницей, например `k7Qp2xVn9sLw4` |
| `TIMEZONE` | Text | `Europe/Moscow` (или свой часовой пояс) |
| `MORNING_AT` / `EVENING_AT` / `WEEKLY_AT` | Text | необязательно: `09:00` / `20:00` / `19:00`, `off` — выключить |

### 6. Включить напоминания
Worker → **Settings → Triggers → Cron Triggers → Add** → `*/5 * * * *` (каждые 5 минут).

### 7. Подключить бота к Telegram
Открой в браузере (подставь свой адрес воркера и секрет):
```
https://tasks-bot.<твой-поддомен>.workers.dev/setup?secret=<WEBHOOK_SECRET>
```
Должно показать `"ok": true`. Это же подключает кнопку «Доска».

### 8. Готово
Напиши боту `/start`. Потом добавь переменную `ALLOWED_USERS` = твой Telegram ID
(его можно узнать у [@userinfobot](https://t.me/userinfobot)) — тогда бот будет отвечать только тебе
**и тем, кого ты пригласишь в проект** через `/invite`.

Перенос старых задач: открой «Избранное», выдели нужные сообщения → Переслать → в бота.

### Обновление
Когда выходит новая версия — снова открой **Edit code**, вставь новый `worker.js`, **Deploy**,
и ещё раз открой ссылку `/setup?secret=…` (обновит команды и кнопку доски). Данные сохраняются.

## Для разработки
```
src/bot.js      — логика бота
src/app.html    — доска (Telegram Mini App)
npm run build   — собрать worker.js (его вставляют в Cloudflare)
npm test        — сборка + тесты (Node 22+, база эмулируется через node:sqlite)
npx wrangler deploy — деплой из командной строки, см. wrangler.toml
```
